# フジクラ（5803）分析ノート

作成日: 2026-06-13  
対象: 株式会社フジクラ（東証プライム、5803）

## まずの結論

フジクラは、生成AI・データセンター投資を背景に、情報通信事業が業績を強く牽引している。2026年3月期は売上高1兆1,824億円、営業利益1,887億円、営業利益率16.0%。特に情報通信事業は売上高6,530億円、営業利益1,527億円まで伸び、営業利益の大半を占める。

一方で、株価は2026年6月12日終値4,256円、会社予想PER45.17倍、PBR12.57倍。すでにかなり高い期待が入っているため、「情報通信の高成長が続くか」「水素など原材料制約が解消されるか」「関税影響が想定内か」を次回決算で確認してから判断する。

## 投資仮説

1. 生成AI・データセンター向け光配線需要が、情報通信事業の数量とミックスを押し上げる。
2. データセンター向け比率が高まることで、情報通信の営業利益率が改善する。
3. 2028中期経営計画では、2028年度に売上高1.6兆円、営業利益3,150億円、営業利益率19.7%、ROE28.5%、ROIC21.6%を狙う。
4. 2026-2028累計で成長投資3,000億円、戦略投資1,000億円、株主還元2,200億円を計画。AIインフラ需要を取りに行く攻めの投資局面。

## 反証条件

- 情報通信の売上成長が会社想定を下回る。
- 水素など原材料調達制約で、出荷・利益率が想定より悪化する。
- データセンター向けの利益率が維持できず、情報通信の営業利益率25%台が崩れる。
- 関税還付や価格改定が想定未達となる。
- エレクトロニクス、自動車、エネルギーの弱さが情報通信の伸びを相殺する。
- 高PER・高PBRを許容できない市場環境に変わる。

## 次回チェック

- 2027年3月期1Q決算で、情報通信の売上進捗と営業利益率を見る。
- Q&Aで示された「データセンター市場は年率20-30%成長」の見立てが維持されるか確認。
- 水素調達の代替調達・内製増強の進捗を見る。
- 日米の大型設備投資、日本400億円・米国最大2,600億円の稼働時期と投資負担を確認。
- 株価が4,000円割れの場合は仮説の毀損有無、5,000円超の場合は期待先行の度合いを確認。
