# 株式分析 personal-doc

株式分析の個人メモをローカルHTMLで管理するための小さな作業場です。

## 開く

`personal-doc/index.html` をブラウザで開きます。

## 保存

銘柄、ノート、チェック状態はブラウザの `localStorage` に保存されます。ブラウザや端末を変える場合は、画面下部のデータ欄からJSONを書き出してください。

## 管理対象

- 銘柄ウォッチリスト
- 投資仮説、目標価格、見直し日
- 決算、ニュース、リスク、売買判断のメモ
- 分析前チェックリスト
- JSONバックアップ

## 追加ノート

- `notes/2026-06-13_fujikura_5803_analysis.md`: フジクラ（5803）の初回分析ノート。
- `assets/seed-data.js`: 画面を再読み込みしたとき、フジクラの銘柄と初回分析メモを一度だけローカル保存へ追加します。

## 注意

この画面は投資判断の記録用です。市場価格、財務データ、ニュースは自動取得しません。
